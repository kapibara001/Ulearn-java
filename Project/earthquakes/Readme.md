# **Проект по JAVA**
## **5 вариант**

---

### Введение

Данный проект представляет собой Java-приложение для анализа данных о землетрясениях. Приложение считывает данные из CSV-файла "Землетрясения.csv", парсит их, сохраняет в базу данных SQLite и предоставляет графический интерфейс для выполнения запросов и визуализации данных в виде графиков.

Основная функциональность включает:
- Парсинг CSV-файла с данными о землетрясениях.
- Сохранение данных в реляционную базу данных (таблицы: earthquake, state, magnitude).
- GUI с возможностью:
  - Расчета средней магнитуды землетрясений для заданного штата.
  - Поиска штата с самым глубоким землетрясением за указанный год.
  - Отображения столбчатой диаграммы количества землетрясений по годам.

Проект использует Java 17 и Maven для сборки.

### Модели данных

- **Earthquake**: Содержит информацию о землетрясении (ID, номер, тип магнитуды, значение магнитуды, ID штата, время).
- **Magnitude**: Типы магнитуд (ID и название типа).
- **State**: Штаты/регионы (ID и название).

---

### Основные классы
- **Create_parse_data** - получение информации из CSV файла, проверка и заполнение базы данных.
- **Schedule** - класс для работы с данными (графики, вывод данных в консоль, GUI для запросов).

---

### Используемые модули
- **openCSV** - для получения данных из CSV-файла.
- **JFreeChart** - нужен для рисования графиков по данным из базы данных.
- **JUnit и Mockito** - необходимы для покрытия кода тестами.
- **Jacoco** - генерация отчета по покрытию тестами.
- **SQLite JDBC** - драйвер для работы с базой данных SQLite.
- **Maven Shade Plugin** - для создания fat-JAR с зависимостями.

---

### Требования
- Java 17 или выше
- Maven 3.6+
- Файл данных: `Землетрясения.csv` в корневой папке проекта

---

### Полезные команды
- `mvn test` - запуск тестов.
- `mvn clean test` - чистый (очистка перед запуском) запуск тестов.
- `mvn verify` - полная верификация (с покрытием). Запускает полный цикл - тесты, компиляция и генерация отчетов по покрытию (Jacoco) и сборку JAR.
- `mvn clean package` - сборка fat-JAR с зависимостями.

---

### Заметки
1) Файл `dependency-reduced-pom.xml` генерируется автоматически плагином Maven Shade Plugin (сборка fat-JAR). Вручную изменить нельзя - содержит улучшенный код из pom.xml.
2) Результаты тестов хранятся в файле `target/site/index.html`.
3) В yml файлах хранятся конфигурации GitHub Actions - инструкции, которые должен делать GitHub автоматически. Эти файлы читаются при действиях с GitHub'ом - `Push`, `request_pull` в ветку `main` и все остальное, на что настроены данные файлы конфигурации.
4) В ходе создания проекта была совершена интеграция `CD(Continuous Delivery or Development)/CI(Continuous Integration)` - непрерывная интеграция и непрерывное развертывание, и автотестов (yml-файлы).
5) База данных SQLite создается автоматически в файле `earthquakes.db` в корне проекта.
